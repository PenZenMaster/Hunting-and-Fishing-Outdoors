### 🔴 Category Filtering (In Progress)

**Problem:** New amenities don't show up based on property type checkboxes (Fishing Charter, Hunting, etc.) until "Hunting and Fishing" is unchecked.

**Root Cause:** The `taxonomy_terms` meta field is empty for new amenities. This field should contain an array of property_action_category IDs that the amenity applies to.

**Current State:**
- Existing amenities: Empty taxonomy_terms (also broken?)
- New amenities: Empty taxonomy_terms
- All amenities have ALL property type meta set (is_fishing, is_hunting, etc.)

**Analysis Completed:**
